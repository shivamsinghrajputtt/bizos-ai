# BizOS AI

AI-powered universal Business Operating System.

## MVP
- Multi-tenant business workspace
- Business-type module configuration
- Leads, customers and tasks
- Knowledge base foundation
- AI-ready conversation layer
- Follow-up automation foundation
- Responsive SaaS dashboard

## Stack
Next.js + TypeScript + Tailwind CSS
Supabase/PostgreSQL
FastAPI (planned)
AI/RAG + workflow automation (planned)

## Principle
One core engine, many business niches.
